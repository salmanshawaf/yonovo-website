## ⛔️ Golden rules — read before doing anything

1. **Verify before you act. Do not trust this file blindly.** It was written from audit data gathered on the dates noted in each task. The repo and live site are the source of truth and may have changed. For every task: (a) locate the real code, (b) confirm the problem still exists, (c) confirm the fix is appropriate, then implement.
2. **Make minimal, targeted changes.** Don't refactor unrelated code. One concern per commit where practical.
3. **Verify each change after implementing** using the "How to verify" steps in the task. Run the build (`next build` / the repo's build script) and lint before considering a task done.
4. **Never change canonical host, redirects, robots, or sitemap behavior without re‑reading the relevant config first** — these have site‑wide SEO impact.
5. **If a task is ambiguous or the repo contradicts it, stop and flag it** rather than guessing. Add a note under the task describing what you found.
6. When you complete a task, update its **Status** line here (and add a dated note to the Changelog).
